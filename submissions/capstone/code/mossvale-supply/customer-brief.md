# Mossvale Supply

Mossvale Supply distributes warehouse and retail supplies from three regional
offices. A small platform team supports a service used by warehouse staff and
keeps development and production accounts separate.

The service uses PostgreSQL for application data and Vault for database access.
The team also uses Terraform for local infrastructure records and GitHub
Actions for repository changes.

Leadership is considering growth to several platform teams. Its current
planning notes cover team separation, recovery, policy controls, key
protection, support, and hosted operations. Operator staffing, recovery
targets, service boundaries, and budget have not yet been set.
